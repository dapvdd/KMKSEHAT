# Asset directory

Gunakan folder ini untuk asset final yang ingin menggantikan ilustrasi SVG pada hero atau section refleksi.

- Simpan gambar yang sudah dioptimasi (WebP/AVIF jika memungkinkan).
- Beri nama file yang deskriptif, misalnya `hero-andong.webp`.
- Referensikan asset dari komponen React menggunakan path `/assets/nama-file.webp`.

Saat ini halaman menggunakan ilustrasi SVG lokal di `src/App.jsx`, jadi website tetap runnable tanpa asset eksternal.
